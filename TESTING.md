# Sun Panels 2.0.0 (26.1.2): что проверить

Собрать: `./gradlew build`, запуск: `./gradlew runClient`. Код не компилировался у меня: в песочнице нет Maven NeoForge и Java 25. Синтаксис проверен `javac`, формула выработки прогнана тестом.

## 1. Сборка
- [ ] `./gradlew build` проходит. Если падает на компиляции, пришли лог: ниже список мест, где я не смог сверить API по исходникам.

## 2. Панели
- [ ] Панель под открытым небом днём: в GUI «СОЛНЦЕ», выработка 32 / 128 / 512 RF/t в ясный полдень.
- [ ] Стекло прямо на панели: выработка та же. Камень сверху: «НЕТ ДОСТУПА К НЕБУ», 0.
- [ ] Ночью «НЕТ ДНЕВНОГО СВЕТА», 0. На рассвете и закате выработка плавно растёт и падает. В дождь ниже.
- [ ] Энергия копится до 4 000 / 16 000 / 64 000, переживает перезаход в мир.
- [ ] Наведение на полосу энергии слева показывает подсказку.
- [ ] Панель рядом с машиной (любой мод с FE на 26.1.2) сама отдаёт ей энергию.

## 3. Трубы
- [ ] Панель → 10 базовых труб → машина: энергия доходит.
- [ ] Ветвление на 2–3 машины: делится примерно поровну.
- [ ] Цепь из базовых и элитных труб: не больше 100 RF/t (самая медленная).
- [ ] Сломать трубу посередине: машина за разрывом перестаёт получать. Поставить обратно: снова получает.
- [ ] Поставить машину к уже лежащей трубе (и наоборот): подключается без перезахода.
- [ ] Трубы не ломают TPS: 500 труб + 50 панелей, `/neoforge tps` без изменений.

## 4. Прочее

- [ ] Русский и английский языки.

## Не сверено с исходниками (по памяти и по праймеру 26.1)
- `level.getEffectiveSkyBrightness(BlockPos)` в `SolarPanelBlockEntity.refreshSky`. Праймер NeoForge 26.1 его называет, но сигнатуру я не видел. Если нет такого метода, замени на расчёт неба из `level.getBrightness(LightLayer.SKY, above)` и затемнения неба; вся логика в одной строке.
- `level.canSeeSky(BlockPos)` — есть в исходниках NeoForge 26.1.
- `BlockBehaviour.propertiesCodec()` и `RecordCodecBuilder` в `codec()` блоков.
- `GuiGraphicsExtractor`, `extractBackground`, `extractLabels`, `setTooltipForNextFrame`, `pose().pushMatrix()` — взяты из Void Recycler, который работает.
- Подписи `updateShape(...)`, `useWithoutItem(...)`, конструктор `BlockEntityType`, `BlockCapabilityCache`, `EnergyHandler`, `EnergyHandlerUtil.move`, `SnapshotJournal`, `Transaction` — сверены с исходниками NeoForge 26.1.x.
